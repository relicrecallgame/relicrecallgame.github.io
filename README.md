# relicrecallgame.github.io

Relic Recall'ın herkese açık sitesi (GitHub Pages). Bu klasörün içindekiler `relicrecallgame/relicrecallgame.github.io` reposunun köküne kopyalanır; `app-ads.txt` de kökte durur.
Üretici: `Docs/Magaza/site_uret.py` (Ege Tycoon'daki ile aynı düzen). Yasal metinler: `Docs/Magaza/Legal/`.

| Dosya | Kullanıldığı yer |
|---|---|
| `index.html` | Destek sayfası: App Store "Support URL" ve "Marketing URL", Google Play "Website" |
| `privacy.html` | Gizlilik politikası: iki mağaza, AdMob, oyun içi Hakkında |
| `terms.html` | Kullanım koşulları |
| `assets/` | Sayfaların görselleri |
| `app-ads.txt` | AdMob doğrulaması — kopya; geçerlisi stüdyo sitesinin kökünde |
| `config.json` | Oyunun açılışta okuduğu reklam ayarı |
